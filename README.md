# Mi Sitio Web SISE

## Descripción
Proyecto colaborativo desarrollado como parte de la formación en análisis y desarrollo de software (ADSO). Su objetivo es aplicar el uso de Git y GitHub junto con el desarrollo web básico (HTML), trabajando en equipo mediante el uso de ramas y control de versiones.

## Integrantes

## Tecnologías utilizadas
- HTML
- Git
- GitHub
- Visual Studio Code

## Cómo ejecutar
1. Descargar o clonar el repositorio
2. Abrir la carpeta del proyecto en Visual Studio Code
3. Ejecutar el archivo `index.html` en un navegador web

## Estructura del proyecto
- index.html → Página principal
- servicios.html → Página de servicios
- README.md → Documentación del proyecto

## Objetivo
Desarrollar un sitio web básico aplicando trabajo colaborativo, buenas prácticas en Git y estructura HTML.
